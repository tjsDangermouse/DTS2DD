DTS to AC-3 Converter - third-party software
============================================

This installation includes three separate programs that the converter runs as
external processes. They are not linked into the converter.

1. FFmpeg (folder: ffmpeg\)
   Used for AC-3 / E-AC-3 conversion, probing and independent verification.
   Build: gyan.dev "release essentials" (see FFmpeg-SOURCE.txt for version).
   Licence: GNU General Public License version 3 (see FFmpeg-LICENSE.txt).
   Source code: https://ffmpeg.org/download.html and https://www.gyan.dev/ffmpeg/builds/

2. LibreMPEG (folder: librempeg\)
   Used only for Dolby TrueHD encoding.
   Built from https://github.com/librempeg/librempeg at the commit listed in
   LibreMPEG-SOURCE.txt with --enable-agpl --enable-zlib, and modified by the
   patch included in this folder (librempeg-truehd-peak-bitrate.patch).
   Licence: GNU Affero General Public License version 3 or later
   (see LibreMPEG-COPYING.AGPLv3.txt and LibreMPEG-LICENSE.md).
   Corresponding source code: the commit above. The exact build commands are
   in .github/workflows/windows-installer.yml of
   https://github.com/tjsDangermouse/DTS2DD

3. tsMuxeR (folder: tsmuxer\)
   Used only for the experimental MKV to M2TS remux.
   Build: official tsMuxer 2.7.0 Windows x64 release (see tsMuxer-SOURCE.txt),
   unmodified.
   Licence: Apache License 2.0 (see tsMuxer-LICENSE.txt).
   Source code: https://github.com/justdan96/tsMuxer (tag 2.7.0)
